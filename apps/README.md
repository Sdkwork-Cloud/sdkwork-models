# SDKWork Models Applications

Application roots for the `sdkwork-models` product.

| Application root | Purpose |
| --- | --- |
| `sdkwork-models-pc/` | PC browser catalog explorer and operator-facing catalog tooling |

Consumer applications such as ClawRouter embed the catalog through `@sdkwork/models` or import the
catalog JSON directly. They do not replace this repository's owned SDK workspace under `sdks/`.
