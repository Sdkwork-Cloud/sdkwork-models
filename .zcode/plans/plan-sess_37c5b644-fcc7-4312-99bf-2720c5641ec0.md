## 目标
为模型目录增加「适用范围」：`usageScopes: string[]`（枚举 `["coding","chat","agent"]`，coding 即是否支持编程场景）与 `codingVisible: boolean`（默认 true，控制模型是否在代码 IDE 中显示），贯通数据 → API → SDK → 数据库 → 前端五层。已确认字段设计为 usageScopes 数组；默认值采用推荐方案（schema 默认 true，非聊天类模型推断为 false）。

## 字段推断规则（tools/catalog-capability-rules.mjs）
- `coding` ← capabilities 含 `code`；`chat` ← chat-like（chat/reasoning/code/tool）；`agent` ← supportsTools===true
- `codingVisible` ← chat-like 模型 → true；embedding/rerank/媒体/STT/TTS → false（显式回填，可覆盖）
